# ExpertsEarn Partner API

Base URL: `https://YOUR_DEPLOYMENT/api/v1`

Authenticate every request with `x-api-key: YOUR_PARTNER_API_KEY` (or `Authorization: Bearer YOUR_PARTNER_API_KEY`). Keep keys on your server and never place them in browser code.

## Endpoints

- `GET /surveys` — list your surveys and response counts.
- `POST /surveys` — create a survey as a draft. Provide `title`, `questions` (1–100), and optional audience, language, reward and pricing fields.
- `GET /surveys/{id}` — retrieve status and targeting for one of your surveys.
- `GET /surveys/{id}/responses` — retrieve submitted responses as JSON.
- `GET /surveys/{id}/responses?format=csv` — download a CSV export.
- `GET /billing` — retrieve your billing ledger. Optional `limit` query parameter (1–500).

## Survey pricing and audience

Price per completed response must be between **$0.20 and $0.50**. The default is $0.20.

Targeting fields:
- Global: `target_country`, `target_region`, `target_city`
- Rwanda: `target_province`, `target_district`, `target_sector`, `target_cell`, `target_village`
- Demographics: `min_age`, `max_age`, `target_gender`

Supported question types: `single_choice`, `multiple_choice`, `text`, `number`, `rating`, `yes_no`. New surveys are created as drafts and require platform review/publication.

## Required server configuration

Set `SUPABASE_SECRET_KEY` (or legacy `SUPABASE_SERVICE_ROLE_KEY`) as a server-only environment variable. Never expose it with a `NEXT_PUBLIC_` prefix or commit it to Git. API keys are stored as SHA-256 hashes; the raw key must be shown only once when generated by the platform.
